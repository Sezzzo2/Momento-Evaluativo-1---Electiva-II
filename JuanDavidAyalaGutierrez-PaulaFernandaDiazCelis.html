Cloud Computing y sus Modelos de Entrega

¿Qué es Cloud Computing?

"Cloud" o computación en la nube se puede definir como la entrega de recursos informáticos como servidores, software, bases de datos, redes, almacenamiento, y análisis a través de Internet, sin necesidad de poseer o mantener físicamente la infraestructura. Su principal ventaja es la flexibilidad, el pago por uso y la escalabilidad.

3 tipos de modelos de entrega en la computación en la nube:

1. Infraestructura como Servicio (IaaS)

Las provee infraestructura básica de TI, que es básicamente servidores, redes, almacenamiento y máquinas virtuales, aquí el usuario tiene el control sobre el sistema operativo, las aplicaciones y los datos, pero no sobre el hardware físico.

  • Ejemplos: Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform.

2. Plataforma como Servicio (PaaS)

PaaS ofrece una plataforma completa para desarrollar, probar y desplegar aplicaciones, esta se centra más que todo en el entorno de desarrollo.

  • Ejemplos: Azure App Services

3. Software como Servicio (SaaS)

SaaS a comparación de los demás es un software que se entrega a través de internet, aquí el usuario solo accede al servicio sin preocuparse por la instalación, infraestructura o el mantenimiento.

  • Ejemplos: Gmail o Outlook, Google Drive

Modelos de Despliegue en Cloud

Nube Pública

Los recursos (servidores, almacenamiento, aplicaciones) son provistos por un tercero y compartidos entre varios usuarios. Tiene múltiples ventajas: bajo costo inicial, escalabilidad y mantenimiento a cargo del proveedor.

  • Ejemplo: Empresas que alojan sus aplicaciones en servidores de AWS o Azure.

Nube Privada

Infraestructura dedicada únicamente a una organización, puede estar en sus propias instalaciones o gestionada por un proveedor externo. Ofrece mayor control, seguridad y personalización.

  • Ejemplo: Un banco que monta su propia nube para seguridad de datos financieros.

Nube Híbrida

Combina nube pública y privada, distribuyendo las cargas de trabajo según conveniencia (ejemplo: datos sensibles en privada y aplicaciones en pública). Es flexible y óptima en costos y recursos.

  • Ejemplo: Una empresa que usa Google Cloud para analítica y mantiene datos críticos en una nube privada.

Nube Comunitaria

Infraestructura compartida por varias organizaciones con intereses comunes (misión, seguridad, requisitos de cumplimiento).

  • Ejemplo: Universidades compartiendo servicios en una misma nube.

Proveedores de Cloud más Conocidos

  • Amazon Web Services (AWS): servicios de infraestructura, almacenamiento, machine learning, IoT.
  • Microsoft Azure: integración con productos Microsoft, soluciones empresariales, inteligencia artificial.
  • Google Cloud Platform: fuerte en big data, inteligencia artificial y Kubernetes.
  • Oracle Cloud: enfocado en bases de datos y aplicaciones empresariales.
